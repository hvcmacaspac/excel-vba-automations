# ⚙️ Excel VBA Automations

> A collection of Excel + VBA automation projects built to eliminate manual, repetitive recruitment operations workflows.

---

## 🗂️ Projects

| Project | Description | Tools |
|---|---|---|
| [Weekly Sourcing Report] | One-click weekly recruitment report automation with SLA tracking, ATS audit, training score monitoring, and week-over-week comparison | Excel, VBA, XLOOKUP, Power Query |
| [Interview Dispatch] | Transforms raw interview request exports into a clean, dispatch-ready tracker — processing 50+ daily requests across 4 dispatch windows | Excel, VBA, INDEX/MATCH, IFS |

---

## 💡 Why These Projects Exist

Both automations were built to solve the same core problem: **high-volume, error-prone manual work that didn't need to be manual.**

The Weekly Sourcing Report turned a 1–2 hour manual reporting process into a single macro run. The Interview Dispatch automation eliminated repetitive copy-pasting of 50+ daily requests — reducing errors and freeing up time for actual recruitment work.

Neither project was assigned. Both were built independently, out of the belief that if a process is repetitive enough, it should be automated.

---

## 🛠️ Tools Used

- **Microsoft Excel** — report structure, formatting, and output
- **VBA (Visual Basic for Applications)** — full workflow automation
- **XLOOKUP + INDEX/MATCH** — dynamic cross-sheet data validation
- **VLOOKUP + IFS** — mapping and conditional logic
- **Power Query** — data transformation and modeling
- **FormulaR1C1** — dynamic formula injection
- **TextToColumns + DATEVALUE + TIMEVALUE** — data parsing and cleanup
